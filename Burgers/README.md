# Burgers

```bash
python atm.py
python random_lst.py
```

Before the first run, generate `data/Burger.mat` by following the instructions
in [`data/README.md`](data/README.md). The three MATLAB source files needed to
recreate the dataset are included, but the generated dataset is not distributed
with the repository.

The experiment configuration is defined in `config.py` and `protocol.json`.
Outputs are written under `results/`.
